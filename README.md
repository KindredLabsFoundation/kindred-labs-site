# Kindred Labs Foundation

The official website for Kindred Labs Foundation, an AI ethics nonprofit dedicated to building governance infrastructure for ethical AI development.

## About

This is the public website for kindredlabsfoundation.org. The site serves as the public face of the Foundation, hosting the Upstream Governance Framework, CDRP recruitment portal, and public governance forms.

- **Live site:** [https://www.kindredlabsfoundation.org](https://www.kindredlabsfoundation.org)
- **GitHub org:** [https://github.com/KindredLabsFoundation](https://github.com/KindredLabsFoundation)

## Tech Stack

| Component | Technology |
|---|---|
| Framework | ASP.NET Core 10, Razor Pages |
| ORM | Entity Framework Core 10 (Npgsql) |
| Database | PostgreSQL on Supabase |
| Identity | ASP.NET Core Identity |
| PDF Generation | iText7 Community 9.6.0 |
| Email | Postmark 5.3.0 |
| Signature Capture | Signature Pad (JavaScript library) |
| Localization | .resx resource files, culture-prefixed routing |
| Deployment | Google Cloud Run |
| CI/CD | GitHub Actions |
