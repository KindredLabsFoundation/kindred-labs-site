# Kindred Labs Foundation

The official website for Kindred Labs Foundation, an AI ethics nonprofit
dedicated to building governance infrastructure for ethical AI development.

## About

This repository contains the source code for kindredlabsfoundation.org,
including the Upstream Governance Framework interactive tools, public forms,
and CDRP recruitment portal.
